2. 08:00–24:00 — AGENTS + TRAZABILIDAD

Repo → Agents. Crea una sesión:

Investigate this repository.

Find the most important issue that could cause a production incident.

Do not modify code initially.

Explain:
- the evidence
- affected files
- likely failure path
- what still requires human verification

Only after the investigation, propose the smallest safe remediation.

“No miréis todavía la respuesta. Mirad cómo trabaja.”

“Aquí puedo auditar tools, búsquedas, comandos y diffs. Esto es trazabilidad.”
