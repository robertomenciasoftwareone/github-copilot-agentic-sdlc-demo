ACCIÓN

Crea una nueva sesión.

PEGAS
Investigate this repository.

Find the most important issue that could cause a production incident.

Do not modify code initially.

Explain:
- the evidence
- affected files
- likely failure path
- what still requires human verification

Only after the investigation, propose the smallest safe remediation.

DICES
